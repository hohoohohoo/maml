================================================================================
NOTE ON --test_cell_types NONE
================================================================================
We currently pass `--test_cell_types NONE` for ALL 4 builds.  This means each
train file contains ALL non-INV cells from the lib library, regardless of the
topology_type suffix in the filename. The intra vs agnostic distinction here is
PURELY filename — both files contain the same data.

The validation script (when written) is what decides which cells are held out
for intra vs agnostic evaluation, not the training-set construction. If a later
experiment wants a stricter train/test split (e.g. exclude AN4D0 / SDFSNQD0
etc. from training), re-run with `--test_cell_types AN4D0 ND3D0 ...` for intra
and `--test_cell_types OA21D0 SDFSNQD0 ...` for agnostic. The 1-D MLP cell-type
filter matches cell-name prefix exactly (case-insensitive) — see
`filter_pin_data_by_cell_type` in the builder.
