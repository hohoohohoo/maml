[C2] On Technical Novelty (R-B W3/Comments; echoed by R-C)

We thank R-B for pressing on novelty. MAML provides the core generalization lever — a single meta-initialization that supports few-shot adaptation across the task distribution — and our technical content is a domain-specific reformulation designed to extract that lever maximally on a task distribution it does not natively cover: per-cell delay-LUT regression across unseen topologies. The three axes we develop — the cell-identity-free current-path representation (detailed in [C1]), the decoupled device-physics features (N-a), and the dual-stage selective adaptation (N-b) — each align a specific bottleneck (representation, features, adaptation) with MAML's bi-level optimization so that the meta-initialization becomes topology-transferable. The ablations in Sec. 5.3 / Figs. 5–6 measure successive layers of this one MAML-based system rather than separate methods.

(N-a) Decoupled device-physics features as the meta-learning signal (Sec. 3.1). What transfers across topologies is device physics, not gate behavior — hence T_ox, DIBL, SCE as independent node features rather than a single lumped V_th. The same rationale governs the current-path representation in [C1]: both axes deliberately avoid cell-identity-bound quantities. Going from MLP_MAML to GCN_MAML under the same MAML procedure and adaptation, varying only the feature/graph granularity, isolates this effect — the additional gain is attributable to the representation, not to the mere presence of MAML.

(N-b) Dual-stage selective adaptation (Sec. 3.4). Adaptation is two-stage rather than vanilla MAML inner-loop SGD: a closed-form Δ-scale + offset alignment first, then Adam-based refinement only when the residual warrants it. Paper Table 6 quantifies this split — alignment alone already recovers most per-task accuracy (evidence that MAML pretraining produced a topology-transferable initialization), and the selective-Adam second stage closes the residual gap while remaining faster than Full Adam by skipping refinement on tasks already aligned.
